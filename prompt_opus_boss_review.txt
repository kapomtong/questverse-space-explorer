- energy=0 → lose → heal 1 → end screen; bossHp=0 → win → badge + 200XP

## สิ่งที่ต้องการจากคุณ
ตรวจ boss.js รอบสุดท้าย — หาบั๊กที่อาจหลุด:
1. Memory leak: timers/RAF/listener หลัง cleanup — ตรวจ mount ซ้ำ 2 ครั้งจะมีปัญหาไหม
2. Race condition: loadQuestion ขณะ player ยืนบน pad — holding logic ถูกไหม
3. Edge case: formatFrac แปลงเศษส่วนในคำถาม → DOM textContent อาจไม่ตรง (เช่น '2/5 + 1/5' → '25 + 15') — ตรวจว่า collision/hint ทำงานถูกไหม
4. Logic: endGame ทำงานตอน energy=0 หรือ bossHp=0 — ตรวจว่า stop loop ครบ (clearInterval, cancelAnimationFrame, removeEventListener)
5. Balance: fireball ยิงหา player — travel time ช้าพอให้ dodge ไหม
6. โจทย์: คำถามสุ่ม 10 ข้อจาก 125 — ตรวจว่าไม่ซ้ำกันไหม
7. Performance: gameLoop ทุก frame — มีอะไรใน loop ที่ควร optimize ไหม
