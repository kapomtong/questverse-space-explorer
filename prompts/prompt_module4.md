## งาน Module 4 — code block 1 ไฟล์: js/questions.js

สร้าง object `QV.QUESTIONS` เก็บคำถาม **ครบ 125 ข้อ** — ดาว 5 ดวง × โซน 5 โซน × 5 ข้อต่อโซน — ระดับเนื้อหาจริงของนักเรียนชั้น ม.1 ตามหลักสูตรแกนกลางฯ (ใหม่ 2551 ฉบับปรับปรุง) — เนื้อหาต้อง**ถูกต้องตามหลักสูตรจริง** เช่น:

### 1. numberon (คณิตศาสตร์) — เนื้อหาม.1 เทอม 1-2
โซน 1: จำนวนเต็ม (การบวก/ลบ/คูณ/หารจำนวนเต็ม, เส้นจำนวน)
โซน 2: เศษส่วนและทศนิยม (การบวก/ลบ/คูณเศษส่วน, ทศนิยม)
โซน 3: เลขยกกำลัง (สมบัติ, รูปแบบเลขยกกำลัง)
โซน 4: อัตราส่วน สัดส่วน ร้อยละ
โซน 5: กราฟและการแปลงทางเรขาคณิต

### 2. bionia (วิทยาศาสตร์)
โซน 1: กระบวนการทางวิทยาศาสตร์
โซน 2: สารในชีวิตประจำวัน (สถานะของสาร, การแยกสาร)
โซน 3: แรงและการเคลื่อนที่
โซน 4: พลังงานและรูปแบบพลังงาน
โซน 5: สิ่งแวดล้อมและทรัพยากรธรรมชาติ

### 3. aksara (ภาษาไทย)
โซน 1: ชนิดของคำ (คำนาม สรรพนาม กริยา)
โซน 2: คำบุพบท คำอุทาน คำสันธาน
โซน 3: การแต่งประโยค (ประโยคความเดียว ความรวม)
โซน 4: คำราชาศัพท์เบื้องต้น
โซน 5: การสรุปใจความ / บทร้อยกรองเบื้องต้น

### 4. lingua (ภาษาอังกฤษ)
โซน 1: Greetings & Introductions
โซน 2: Present Simple Tense
โซน 3: Vocabulary: Animals, Jobs
โซน 4: Present Continuous Tense
โซน 5: Prepositions of place & Everyday conversation

### 5. civilis (สังคมศึกษา)
โซน 1: ศาสนา ศีลธรรม จริยธรรม
โซน 2: หน้าที่พลเมือง วัฒนธรรม
โซน 3: เศรษฐศาสตร์เบื้องต้น
โซน 4: ประวัติศาสตร์ (ยุคสมัย, เครื่องมือทางประวัติศาสตร์)
โซน 5: ภูมิศาสตร์ (เครื่องมือทางภูมิศาสตร์, ทวีป)

## โครงสร้างข้อมูล (เคร่งครัด — ใช้รูปแบบนี้เท่านั้น)
```javascript
QV.QUESTIONS = {
  numberon: {
    0: [
      { q: "...", choices: ["...", "...", "...", "..."], answerIdx: 2, hint: "คำใบ้..." },
      ... // 5 ข้อ
    ],
    1: [...], 2: [...], 3: [...], 4: [...]
  },
  bionia: { ... }, aksara: { ... }, lingua: { ... }, civilis: { ... }
};
```
- choices: array 4 ตัวเลือก **ตำแหน่งคำตอบถูกต้องต้องสับเปลี่ยนคละกัน** (answerIdx 0-3 กระจาย ไม่ซ้ำ pattern เดิม)
- q ใช้ escapeHtml ฝั่งแสดงผล — เนื้อหาในข้อมีตัวเลข/สัญลักษณ์ได้
- hint: คำใบ้ภาษาไทยสั้นๆ ช่วยให้คิด (ไม่บอกคำตอบตรงๆ)
- ใช้ const QV = window.QV || {}; บนสุด และ window.QV = QV; ท้ายไฟล์
