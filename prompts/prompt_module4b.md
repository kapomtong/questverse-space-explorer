## บริบท
ตอบไปก่อนแล้วบางส่วน (numberon 25 ข้อ, bionia 25 ข้อ, aksara 25 ข้อ, lingua โซน 0-3: 20 ข้อ = 95 ข้อ) — **ถูก API ตัดกลางคัน** รอบนี้คุณต้องตอบ **เฉพาะส่วนที่เหลือ 30 ข้อ**:
1. ดาว lingua (ภาษาอังกฤษ) โซน 4 และ 5 (โซนละ 5 ข้อ = 10 ข้อ) — Present Continuous Tense, Prepositions of place & Everyday conversation
2. ดาว civilis (สังคมศึกษา) ครบทั้ง 5 โซน (โซนละ 5 ข้อ = 25 ข้อ):
   - โซน 0: ศาสนา ศีลธรรม จริยธรรม
   - โซน 1: หน้าที่พลเมือง วัฒนธรรม
   - โซน 2: เศรษฐศาสตร์เบื้องต้น
   - โซน 3: ประวัติศาสตร์ (ยุคสมัย เครื่องมือทางประวัติศาสตร์)
   - โซน 4: ภูมิศาสตร์ (เครื่องมือทางภูมิศาสตร์ ทวีป)

## โครงสร้าง (เคร่งครัด — ตอบเฉพาะ object นี้)
```javascript
const QV2 = {
  lingua: {
    4: [{ q: "...", choices: ["...","...","...","..."], answerIdx: 1, hint: "..." }, ...5ข้อ],
    5: [...5ข้อ]
  },
  civilis: {
    0: [...5ข้อ], 1: [...5ข้อ], 2: [...5ข้อ], 3: [...5ข้อ], 4: [...5ข้อ]
  }
};
```
- ระดับเนื้อหาเด็ก ม.1 จริง คำถามต้องถูกต้องตามหลักสูตรแกนกลางฯ
- lingua ตอบเป็นภาษาอังกฤษ, civilis ตอบเป็นภาษาไทย
- choices 4 ตัวเลือก คำตอบกระจาย answerIdx 0-3 คละกัน
- hint คำใบ้ภาษาไทยสั้นๆ (lingua ใช้ hint อังกฤษง่ายๆ)
- เขียนให้กระชับ (ห้ามบรรยายยาว) — 12000 ตัวอักษร = ขีดจำกัด **ถ้าเขียนครบ 30 ข้อแล้วเหลือพื้นที่น้อย ให้จบ object ทันที** อย่าเขียนเกิน
