คุณเขียน boss.js (engine) เสร็จไปแล้วรอบก่อน ตอนนี้ให้เขียนอีก 2 ไฟล์ที่เหลือเท่านั้น — เขียนให้จบครบในข้อความเดียว

API นี้ไม่มีเครื่องมือใดๆ ห้ามใช้ tool เด็ดขาด ตอบเป็น Markdown code blocks (```javascript และ ```css)

## ไฟล์ที่ 1: js/bossHall.js
SPA screen: QV.app.screens['boss-hall'] = { mount(root, params){...}, cleanup(){} };
หน้าที่ทำ:
1. สร้าง layout HTML: header (โปรไฟล์: ชื่อ QV.state.player.name, XP, ยศ, เลเวล, energy bar) + ปุ่ม "กระดานผู้นำ" (alert รายการ top จาก QV.state.leaderboard || []) + ปุ่ม "Time Attack" (QV.app.navigate('time-attack')) + ปุ่ม reset progress
2. Grid การ์ดบอส 5 ใบ loop จาก BOSS_CONFIGS (const นี้ declare ที่ top ของ boss.js — bossHall.js อ้างอิง BOSS_CONFIGS ได้เลย ถ้า undefined ให้ define default array 5 ตัวเอง):
   - การ์ด: bossImg, name, subject (ชื่อไทย: math=คณิตศาสตร์, science=วิทยาศาสตร์, thai=ภาษาไทย, english=ภาษาอังกฤษ, social=สังคมศึกษา), difficulty = '⭐'.repeat(cfg.difficulty), requiredXP
   - ถ้า QV.state.player.xp < cfg.requiredXP: การ์ด .locked (opacity 0.5, icon 🔒 + ข้อความ "ต้องการ XP {need}") กดไม่ได้
   - ถ้าปลดแล้ว: ปุ่ม "ท้าประจัญ!" → เรนเดอร์หน้าเลือกไอเทม
3. หน้าเลือกไอเทม (overlay หรือแทนเนื้อหา): 3 การ์ดไอเทม — 🛡️โล่ (assets/item_shield.webp, "กันดาเมจครั้งแรก 1 ดวง"), 🧪ยา (assets/item_potion.webp, "ฟื้น HP 1 ดวงทุก 3 คำตอบถูก"), ⚡Boost (assets/item_boost.webp, "บอสช้าลง 40% ใน 10 วินาทีแรก") + ปุ่ม "เลือกและเริ่มสู้" — คลิก = QV.state.selectedItem = id; saveState; mount boss: const b = new BossBattle(root, cfg.id); b.mount(); และ register cleanup
4. CSS คลาส: .boss-hall {grid 2 คอลัมน์บนมือถือ 3 บน desktop, gap 16px, padding} .boss-card {bg gradient เข้ม border ทอง, border-radius 16px, overflow hidden, hover scale} .boss-card.locked {opacity:.55, filter grayscale} .boss-img {width 100%, height 160px, object-contain} .item-grid {3 คอลัมน์} .item-card {border 2px transparent, เลือกได้, .selected border ทอง} .btn-gold {gradient ทอง ตัวหนา}

## ไฟล์ 2: js/timeAttack.js
QV.app.screens['time-attack'] = { mount, cleanup }
- ใช้ BossBattle engine: const b = new BossBattle(root, 'mathos') หรือ bossID ที่ config ให้ timeLimit=90
- Timer 90 วิ: แสดงบน HUD ที่ 120ms ตอบถูก +5 วิ, พูดจบ 10 ข้อหรือเวลาหมด = จบ
- XP โบนัส: +10 × วินาทีที่เหลือ, victory/defeatเหมือน boss ปกติ + ปุ่มกลับ hall
- CSS: .ta-timer {ฟอนต์ใหญ่ สีเขียว หนึ่งกว่า 10 วิสุดท้ายแดง}

## ข้อมูล BossBattle API ที่คุณออกแบบไว้ (ใช้ตามนี้):
- new BossBattle(root, bossId) → .mount() / .cleanup()
- constructor อาจรับ options: new BossBattle(root, bossId, {timeLimit: 90})
- gameState.score = xp ที่ได้; victory/death ส่งค่าผ่าน callback config.onFinish({won, xp}) ถ้ามี — ถ้าไม่มี ใช้ button onclick="QV.app.navigate('boss-hall')" ภายใน innerHTML ตามที่คุณเขียนใน showVictory/showDefeat

## Boss configs (BOSS_CONFIGS, reference):
mathos: math, ⭐1, XP 0 | chronos: science, ⭐2, XP 100 | kawi: thai, ⭐3, XP 250 | lex: english, ⭐4, XP 450 | terra: social, ⭐5, XP 700
